End-to-End Compiler Pipeline // All Phases Implemented

PHASE 1
Lexical Scanner
Flex-based scanner recognizing keywords, identifiers, numerics, and units.
PHASE 2
Parser & AST
Recursive-descent grammar parser creating AST nodes with symbol table resolution.
PHASE 3
IR & Codegen
Translates AST into normalized Intermediate Representation and emits Terraform HCL.
PHASE 4
Dual-Mode Normalizer
Converts both NL and form inputs into the single canonical JSON schema.
PHASE 5
Alternatives Engine
Filters hard constraints across clouds and scores 3 feasible candidate profiles.
PHASE 6
Explainable Diff
Provides grounded explanations and rule IDs for every architectural delta.

The Three Novelty Features // Core Innovations

NOVELTY 1

Dual-Mode Normalization

Users can describe infrastructure naturally in conversational English or select options in a structured form. Both modes normalize to an identical schema without bypassing compiler validation.

NOVELTY 2

Constraint-Aware Alternatives

Evaluates multi-cloud hardware catalogues to produce three distinct feasible configurations: Cost-Optimized, Balanced, and Performance-Focused, with itemized budget and constraint checks.

NOVELTY 3

Explainable Configuration Diff

Transparently explains why a recommendation differs from user requirements, citing verified constraint rules, headroom policies, and instance shape constraints.
